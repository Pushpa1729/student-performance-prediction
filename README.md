# 🎓 Student Performance Prediction System

An end-to-end Machine Learning web application that predicts whether a student will Pass or Fail based on academic scores and demographic factors.

## 🔑 Features

- 🔐 Secure Authentication (Sign Up / Sign In + Google OAuth Login)
- 📊 Interactive Dashboard with real-time filters
- 📈 Exploratory Data Analysis with dynamic visualizations
- 🎯 Live ML-powered predictions with confidence scores
- 🤖 Model Insights — Feature importance & performance metrics

## 🛠️ Tech Stack

- **Language:** Python
- **Data Processing:** Pandas, NumPy
- **Machine Learning:** Scikit-learn (Random Forest Classifier)
- **Web Framework:** Streamlit
- **Visualization:** Matplotlib, Seaborn
- **Authentication:** SQLite + Google OAuth

## 📊 Model Performance

- **Algorithm:** Random Forest Classifier
- **Accuracy:** 99.5%
- **Dataset:** Students Performance in Exams (Kaggle)
